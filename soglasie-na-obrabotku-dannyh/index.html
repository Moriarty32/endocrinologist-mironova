1. Предмет согласия

Пользователь даёт согласие на обработку персональных данных: имени, телефона, предпочтительного способа связи и темы обращения — для рассмотрения заявки и согласования консультации.

2. Действия с данными

Сбор, запись, систематизация, хранение, уточнение, использование, обезличивание, блокирование и удаление данных. Обработка может выполняться как с использованием средств автоматизации, так и без них.

3. Цель

Связаться по заявке, согласовать время и формат консультации, ответить на организационные вопросы. Данные не используются для рекламы без отдельного согласия.

4. Медицинские данные

Форма не предназначена для передачи медицинских документов и подробностей здоровья. Для обсуждения клинической информации используется согласованный защищённый канал после записи.

5. Срок и отзыв

Согласие действует до его отзыва. Отозвать согласие можно, направив запрос на info@example.ru. Отзыв не влияет на обработку, которая уже выполнена на законных основаниях.
